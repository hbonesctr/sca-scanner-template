# 📤 Upload Customer Software Here

## Quick Instructions

1. Click "Add file" → "Upload files"
2. Drag customer ZIP file
3. Click "Commit changes"
4. Wait ~10 minutes
5. Download from "Releases" tab

## What Happens Automatically

- ⚙️ ZIP extracts
- 📋 SBOM generates
- 🔒 SAST scans (CodeQL + Semgrep)
- 🛡️ SCA scans (Snyk + Grype)
- 📄 Report creates
- 📦 Release packages

⏱️ **Total Time:** 10-15 minutes
