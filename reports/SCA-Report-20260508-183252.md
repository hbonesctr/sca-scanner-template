## Important Limitations

- Runtime-extracted files are not automatically committed to GitHub.
- Snyk Web GitHub Import will not see files under `/tmp/extracted` unless they are committed to the repository.
- This workflow intentionally uses Snyk CLI from `/tmp/extracted` and optionally `snyk monitor` to publish monitored projects to Snyk.
- GitHub CodeQL is not included by default because GitHub Free private repositories generally do not support GitHub code scanning alerts for private repositories.
